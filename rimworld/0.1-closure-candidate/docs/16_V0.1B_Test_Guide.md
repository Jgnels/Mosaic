# Version 0.1B — Beginner Test Guide

**Status:** Source implemented and isolation-tested; Windows/RimWorld compilation and in-game testing require the owner's installation.

## What this build tests

Version 0.1B is an Observer-only identity-and-persistence test. It should:

- enroll each free colonist once;
- assign a Dagmay `IndividualId` and `LineageId` independent of the colonist's name;
- capture a grounded starting snapshot from available RimWorld pawn information;
- persist identities in a versioned, checksummed external archive;
- link the archive to the RimWorld save;
- preserve IDs through save, quit, restart, load, and rename;
- archive a tracked individual after in-world death; and
- enter read-only safety mode rather than silently replacing identity data when persistence is inconsistent.

It does not create memories, call Google, display a mind tab, reflect, speak, or control pawn behavior. No API key is needed.

## Before replacing 0.1A

1. Close RimWorld completely.
2. Back up the dedicated Dagmay test save.
3. Move the existing `RimWorld\Mods\Dagmay` folder somewhere outside the `Mods` folder. Do not leave both 0.1A and 0.1B under `Mods`, because RimWorld would see duplicate copies of the same mod.
4. Extract the 0.1B source archive into a new folder such as `C:\Dagmay-0.1B`.

## Build

Open the extracted project folder in File Explorer, click the address bar, type `powershell`, and press Enter. Run:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\tools\build.ps1
```

If RimWorld is not in Steam's default folder, use:

```powershell
.\tools\build.ps1 -RimWorldPath "D:\SteamLibrary\steamapps\common\RimWorld"
```

The expected automated-test result is:

```text
Executed 19 tests; 0 failed.
```

The package should be created at:

```text
artifacts\Dagmay-RimWorld-0.1B.zip
```

Do not continue if compilation or a test fails. Preserve the complete PowerShell output for diagnosis.

## Install

Extract the package so these files exist:

```text
RimWorld\Mods\Dagmay\About\About.xml
RimWorld\Mods\Dagmay\Assemblies\Dagmay.RimWorld.dll
RimWorld\Mods\Dagmay\Assemblies\Dagmay.Core.dll
```

Avoid an extra nested folder such as `Mods\Dagmay\Dagmay\About`.

## Test A — Load and enrollment

1. Start RimWorld and confirm Dagmay is enabled.
2. Load a copy of the dedicated Dagmay test colony.
3. Let the game run unpaused for at least 15 seconds.
4. Save under a new name such as `Dagmay_01B_Test_1`.
5. Quit RimWorld completely.
6. Open `Player.log` and search for `[Dagmay] 0.1B`.

The usual log location is:

```text
%USERPROFILE%\AppData\LocalLow\Ludeon Studios\RimWorld by Ludeon Studios\Player.log
```

Expected messages include:

```text
[Dagmay] Version 0.1B loaded. Identity-and-persistence observer active; no pawn-control code is enabled.
[Dagmay] 0.1B enrolled ... IndividualId=... LineageId=...
[Dagmay] 0.1B identity service ready ... Storage=healthy; Path=...
```

There should be one enrollment message for each free colonist. Copy the inventory line for one colonist into a temporary note so its `IndividualId` can be compared after reload.

## Test B — Save/load continuity

1. Start RimWorld again.
2. Load `Dagmay_01B_Test_1`.
3. Let it run for at least 15 seconds.
4. Save as `Dagmay_01B_Test_2` and quit completely.
5. Open the new `Player.log` and search for the chosen colonist's name.

Expected result:

- the identity-service message says `Storage=healthy`;
- existing colonists are listed in `identity inventory` messages;
- the chosen colonist has exactly the same `IndividualId` and `LineageId`; and
- existing colonists are not enrolled as new individuals again.

Stop and preserve the save and log if `READ-ONLY`, `missing`, `mismatch`, `corrupt`, or a red Dagmay error appears.

## Test C — Rename continuity

This test is optional if the current colony or mod list does not provide a safe way to rename a pawn.

1. In a disposable copy of the test save, rename one enrolled colonist using the normal RimWorld interface or an already-installed trusted character-editing mod.
2. Let the game run for at least 15 seconds.
3. Save, quit, and inspect `Player.log`.

Expected message:

```text
[Dagmay] 0.1B observed rename; IndividualId=...; displayName=...
```

The ID must match the identity that the pawn had before the rename.

## Test D — Death archival

This test is optional and must use a disposable save. Do not harm a valued colony merely to complete it.

If a tracked colonist dies during ordinary test play, let the game run for at least 15 seconds, save, and inspect the log. The expected message is:

```text
[Dagmay] 0.1B archived deceased individual ... IndividualId=...
```

After another save/load, the inventory line should retain the same ID with `Lifecycle=Archived`.

## What to report

Report:

1. whether the build ended with `19 tests; 0 failed`;
2. whether Test A showed `Storage=healthy`;
3. whether the same colonist ID appeared after Test B;
4. whether existing colonists avoided duplicate enrollment after reload;
5. any red Dagmay errors; and
6. whether the other installed mods behaved normally.

Never send an API key. Log excerpts containing Dagmay IDs are acceptable for this private test, but do not publish full logs or identity archives without reviewing their contents.
