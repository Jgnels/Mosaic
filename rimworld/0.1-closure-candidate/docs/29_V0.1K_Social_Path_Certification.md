# Dagmay 0.1K — Social Path Certification

0.1K begins the RimWorld 0.1 release-closure track.

The cognitive feature set is frozen at the 0.1J.3 baseline. SyntheticLab research after
that point is intentionally not imported into 0.1K.

## Goal

Certify the real RimWorld path:

`RimWorld social change`
→ `factual event`
→ `stable counterpart IndividualId`
→ `subjective memory`
→ `relationship-sensitive privacy`
→ `reflection-eligible evidence path`
→ `save/reload persistence`

## Automatic sidecar

0.1K writes a diagnostic-only report under the RimWorld config tree:

`Dagmay\Diagnostics\<store-id>-social-certification.txt`

The sidecar is not part of the individual's canonical memory.

## PASS requirements

A PASS requires:

- at least one bounded social event was observed;
- every observed social event has a stable enrolled counterpart link;
- every observed social event produced a subjective memory;
- those memories are `RelationshipSensitive`;
- those memories retain counterpart `IndividualId` provenance;
- at least one social event has enough evidence for the reflection admission policy;
- the same social history is visible after loading the save.

A material opinion change usually requires two events in the same coalescing window before
the reflection path becomes eligible.

A direct relationship change is eligible immediately.

## Certification integrity hardening

Certification format version 2 fails closed unless:

- the event contains exactly two distinct stable `IndividualId` subjects;
- exactly one owner memory links to that event;
- counterpart provenance names the event's exact second stable subject, not merely any non-owner person;
- repeated-opinion evidence counts only events where the same individual is the primary subject;
- identity, experience, and reflection stores are all healthy;
- the report was produced during post-load audit; and
- every `Gate.*` value and `Gate.Overall` agrees with `Status=PASS`.

The sidecar is replaced atomically with a retained prior diagnostic backup. `check-social-certification.ps1` derives the active store from the latest Dagmay load in `Player.log` (or an explicit `-StoreId`) and refuses to use an unrelated historical PASS. `collect-logs.ps1` embeds only that active store's sidecar.
## Test procedure

1. Use a copy of the colony save.
2. Build/install 0.1K.
3. Keep at least two colonists enrolled and active.
4. Provider dispatch may remain paused; event recording and queue admission still operate.
5. Play until Dagmay records one or more social events.
6. Save the game.
7. Reload that save.
8. Run:

```powershell
.\tools\check-social-certification.ps1
```

9. Then collect the combined evidence:

```powershell
.\tools\collect-logs.ps1
```

Upload `artifacts\Dagmay-diagnostics-latest.txt`.

## What this does not certify

0.1K does not claim:

- accurate inference of private motives;
- universal conversation interception;
- canonical relationship-value learning;
- autonomous pawn behavior;
- SyntheticLab canonical SelfModel promotion.

Those remain outside the frozen 0.1 scope.
