# Glossary

**Status:** Draft 0.1

| Term | Definition |
| --- | --- |
| Active lineage | The single authorized running continuation of an identity. |
| Adapter | A component translating an environment or provider into core-owned contracts. |
| Affect | Continuous internal appraisal dimensions that influence cognition; not a claim of felt emotion. |
| Archive | Preserved, inactive identity and life record, especially after death. |
| Autobiographical memory | A subjective memory integrated into the individual's account of itself. |
| Belief | A proposition held with confidence, evidence, and possible contradiction; it need not be true. |
| Bounded perception | Information limited to what the individual could plausibly experience or be told. |
| Canonical state | The authoritative validated state from which current identity projections are derived. |
| Cognitive accessibility | How available a memory is to ordinary retrieval, distinct from whether audit data still exists. |
| Consolidation | Process that integrates, summarizes, promotes, or lowers accessibility of memories while recording provenance. |
| Continuity invariant | Identity persists through an authorized causal lineage rather than through use of one language model. |
| Core autobiographical memory | Rare, identity-shaping memory with strong continuity effects and strict mutation auditing. |
| Dagmay Core | Game- and provider-independent domain responsible for identity, memory, beliefs, affect, relationships, goals, lifecycle, validation, and persistence rules. |
| Decision summary | Concise selected outcome, evidence, factors, and confidence; not hidden model chain-of-thought. |
| Disclosure policy | Rules deciding which internal information may appear in ordinary interaction. |
| Embedding | Rebuildable numeric representation used for semantic retrieval; never canonical identity state. |
| Enrollment pause | Reversible host-service state that stops ordinary Dagmay observation/reflection for an existing individual without deleting or changing identity, lineage, memories, or lifecycle history. |
| Environment event | Adapter-normalized record of something observed in a simulated world. |
| Extrinsic state | World-provided condition such as hunger, temperature, pain, location, injury, or inventory. |
| Fork | A new lineage descended from a shared state after duplication or intentional branching. |
| Graceful degradation | Bounded behavior under failure that preserves critical facts, exposes health, and reduces optional work. |
| Identity seed | Versioned grounded snapshot used to initialize an individual. |
| Individual | A stable identity and its single authorized causal lineage through changing state and experience. |
| IndividualId | Stable Dagmay identifier independent of pawn name, provider, model, and transient object identity. |
| Intrinsic state | Portable-where-meaningful state such as beliefs, trust, values, preferences, goals, and autobiographical identity. |
| Ledger | Append-only sequence of events, proposals, mutations, lifecycle transitions, migrations, and repairs. |
| Lifecycle | Explicit state such as active, unavailable, dead, archived, or forked. |
| Memory mutation | Auditable change to a memory's interpretation, importance, tier, accessibility, or links. |
| Model provider | Replaceable generative or embedding service; it is not the individual. |
| Observer Mode | Clearly separated diagnostic interface for state, provenance, model operations, and system health. It is not ordinary in-world knowledge. |
| Perceived event | One individual's bounded perspective on an environment event. |
| Perspective filter | Adapter logic that selects and limits information plausibly available to an individual. |
| Proposed mutation | Untrusted model-suggested state operation awaiting validation. |
| Reflection | Integration or interpretation task using accepted state and selected experience. |
| RimWorld adapter | Module translating RimWorld state/events into Dagmay contracts and rendering UI projections. |
| Scheduler heartbeat | Periodic opportunity to evaluate background work; not a guaranteed model call per individual. |
| Session request budget | Hard maximum number of concrete provider transport attempts during one RimWorld process/session; local recording and offline queueing do not consume it. |
| Schema migration | Versioned deterministic transformation of persisted data to a newer supported schema. |
| Semantic retrieval | Candidate selection by meaning plus structured filters and inspectable scoring. |
| Snapshot | Checksummed state projection at a known ledger position used for faster load and recovery. |
| Subjective memory | Individual interpretation of perceived experience with appraisal, confidence, affect, and provenance. |
| Validation gate | Single boundary that checks and atomically accepts or rejects proposed canonical mutations. |
