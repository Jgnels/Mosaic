# Mosaic 0.3H — Grounded Compound Appraisal Proposal

## Purpose

Mosaic 0.3H consumes one directly witnessed, admitted current-event appraisal seed and one exact accepted 0.3G grounded developmental-context packet. It produces a bounded, explainable compound appraisal proposal that is inert and read-only.

The proposal is not canonical state, persistence, presentation, provider output, planning, action completion, or pawn authority.

## Current-event seed

`GroundedCurrentEventAppraisalSeed` requires:

- exact owner, lineage, optional counterpart, save, world, store set, checkpoint generation, and checkpoint fingerprint;
- exact event ID, event hash, event tick, and root-event closure;
- admitted and directly witnessed evidence;
- `OWNER_PRIVATE` or `PUBLIC` privacy, never player-only;
- positive-support appraisal families;
- signed bounded affect and relationship dimensions;
- explicit relationship relevance before relationship evidence is admitted;
- stable rule IDs;
- deterministic public self-verification.

Raw dialogue, labels, traits, diagnoses, provider output, recursive context roots, and action claims are not represented.

## Request binding

`ContextualAppraisalRequest` binds the exact seed, accepted v42 materialization request, and accepted v42 packet. It rejects foreign owners, stores, checkpoints, purposes, future evidence, substituted same-generation checkpoints, forged packet fingerprints, and reuse of the current event as its own historical justification.

## Appraisal regimes

Exactly one deterministic regime applies:

| Regime | Current | History |
|---|---:|---:|
| No history | 10000 | 0 |
| Overwhelming current event | 8000 | 2000 |
| Repeated pattern | 4500 | 5500 |
| Contradictory history | 6500 | 3500 |
| Balanced | 6000 | 4000 |

Current and historical dimensional evidence each use one shared L1 budget. Omitted evidence is not renormalized. Largest-remainder allocation retains the original sign of tiny values.

## Output bounds

- at most three supported appraisal families;
- at most six affect-dimension proposals;
- at most four relationship considerations;
- at most sixteen Character Why contributions;
- all values bounded to ±10000 basis points;
- relationship history cannot create a relationship consequence absent from the current event;
- positive and negative evidence remain visible;
- contradiction lowers confidence rather than being averaged away;
- `relationship_considerations` are evidence, not canonical relationship deltas;
- intensity is calibration data, not a presentation command.
