# Mosaic 0.3 Contextual Decision Core Promotion Boundary

## Scope

This packet adds immutable contracts only for:

- contextual Severity Hybrid reaction presentation;
- contextual memory retrieval with Hybrid as the normal balanced strategy;
- bounded developmental HTN plan proposals;
- owner policy calibration that cannot become pawn state;
- structured read-only RimWorld evidence envelopes.

## Explicit non-scope

The packet contains no:

- reaction implementation;
- retrieval scorer;
- planner implementation;
- event hooks;
- save adapter;
- UI;
- provider;
- pawn job;
- Harmony patch;
- action execution;
- canonical character mutation.

## Authority boundaries

- Reaction decisions may present an appraisal but cannot change its meaning.
- Retrieval decisions may select authorized evidence but cannot mutate memory.
- HTN proposals may identify executable candidates but cannot issue jobs or assert outcomes.
- Owner feedback changes policy calibration only and has no IndividualId.
- RimWorld event envelopes distinguish attempts from completed outcomes.
- The adapter emits evidence; it does not commit character state.

## Runtime disposition

No RimWorld runtime test is required while these contracts remain unused. The initial gate is
compile, contract verification, source-authority firewall, and deterministic repeated output.
