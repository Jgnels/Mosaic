## Main conclusions

### Preserve the identity/provenance kernel
No surveyed architecture provides a reason to surrender model-independent `IndividualId`,
`LineageId`, or immutable evidence provenance.

### Memory is plural
Separate:
- canonical evidence;
- episodic memory;
- semantic beliefs;
- working/context memory;
- procedural skill memory;
- developmental/predictive state.

### Use explicit appraisal
Preferred path:

`perceived event → appraisal variables → bounded affect proposal → validation`

### Build temporal beliefs
Beliefs should be:
- sourced;
- uncertain;
- contradicted;
- superseded;
- historically reconstructable.

### Relationships are directed evidence accumulators
A→B differs from B→A.

Direct evidence differs from hearsay.

Beliefs about another's beliefs differ from actual beliefs.

### Start developmental learning simple
Begin with:
- frequency;
- transition probabilities;
- prediction error;
- action→outcome;
- person-conditioned outcome;
- replay variants.

### Event segmentation comes before sensory scale
Compare:
- fixed windows;
- causal rules;
- prediction-error boundaries;
- hybrid segmentation.

### External systems are laboratories
Promising comparison sources:
FAtiMA, GAMYGDALA, PsychSim, Monty, pymdp, Avalanche, Continuum, Melting Pot, MiniGrid,
AI2-THOR, Neural MMO, MineDojo.

None owns Dagmay identity.

## Operational research target

> Does causally ordered personal experience produce stable, history-dependent behavioral
> differentiation that persists under prompt changes and model-provider replacement?

Do not use "sounds human" as the sole metric.

## What the survey argues against

- replacing Dagmay with an off-the-shelf cognitive architecture;
- treating a vector database as the memory system;
- feeding every sensory sample to an LLM;
- letting generated summaries overwrite raw evidence;
- letting emotion be arbitrary prose output;
- sidecars without coordinated checkpoint semantics;
- optimizing directly for humanlike behavior without causal-history tests;
- assuming chronological curriculum alone creates development;
- assuming more model calls create deeper development;
- equating pretrained LLM + memory with a continually learning mind.
