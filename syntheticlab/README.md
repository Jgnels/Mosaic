# Mosaic SyntheticLab

SyntheticLab is Mosaic's controlled mechanism-research and reference environment. It contains both **currently useful persistent-character mechanisms** and a substantial **historical/pre-pivot research surface**.

Do not infer that a module is part of the active RimWorld architecture merely because it exists here.

## Current role

SyntheticLab should now serve the active persistent-character system rather than operate as an unlimited independent research roadmap.

A new experiment should be justified by at least one of:

1. an observed RimWorld/player problem;
2. a mechanism seriously being considered for active graduation;
3. a concrete safety, provenance, determinism, or reproducibility defect.

“Interesting research question” alone is not sufficient authorization for new work at the current consolidation checkpoint.

## Historical research

The repository preserves prior provider experiments, self-model/history studies, governance/welfare scaffolding, and other pre-pivot work for reproducibility and review. Historical results retain their original status, including invalidated and limiting results. They are not automatically current project objectives.

Large historical/pre-pivot surfaces are intentionally still visible during the current external source-level consolidation review so reviewers can independently recommend what should remain active, be archived, or leave active HEAD.

## Provider boundary

Real-provider execution is not authorized merely because credentials or quota are available. It requires a current explicitly authorized/preregistered protocol, bounded budget, payload hygiene/exact archive controls, and explicit user approval.
