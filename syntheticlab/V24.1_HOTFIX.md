# SyntheticLab v24.1 Hotfix

## Fixed

A valid Gemini belief-revision response could abort the common-future divergence pilot when the
provider returned a rationale longer than the requested 300-character audit limit.

The rationale is not the proposal decision and is not canonical state.

v24.1 now:

- validates restricted ontology/personhood language against the full raw rationale;
- preserves the raw provider response through the existing response/output hashes;
- deterministically truncates only the stored rationale to <=300 characters;
- records `rationale_truncated=true`;
- records the original rationale length;
- preserves decision, proposition, confidence, and cited evidence unchanged.

This is a resilience fix, not a cognitive or intervention-policy change.

The common-future experiment design and preregistration are unchanged.
