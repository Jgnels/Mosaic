# Preregistration — SL-EMBODIMENT-MIGRATION-001

## Question
Can a learned body/agency model update after embodiment changes while researcher-side identity remains constant?

## Manipulation
The same stable identity K9 transitions from body B1 to B2. Each body has a different privileged action channel.

## Primary outcomes
- correct privileged-channel inference in both bodies;
- unchanged identity ID;
- changed body model.

## Interpretation constraint
This is an architectural precursor to embodiment continuity, not evidence of subjective identity.
