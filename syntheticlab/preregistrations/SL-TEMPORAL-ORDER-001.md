# Preregistration — SL-TEMPORAL-ORDER-001

## Question
Does chronological ordering carry information for an order-sensitive learner in a changing causal environment?

## Conditions
- chronological stream;
- identical event multiset shuffled.

## Primary metric
Accuracy for the currently active causal regime.

## Required validity check
The chronological and shuffled conditions must contain exactly the same event multiset.

## Interpretation constraint
A result shows that order can matter to development; it does not establish that any particular human memory mechanism is correct.
