# Preregistration — SL-FALSE-BELIEF-001

## Question
Can the architecture represent world truth, own belief, and a model of another agent's belief separately?

## Scenario
O7 moves from L1 to L2 after Agent B loses observational access. Agent A observes the move.

## Expected
- world truth: L2
- A belief: L2
- A's model of B belief: L1

## Interpretation constraint
Passing demonstrates representational capacity only, not spontaneous Theory of Mind.
