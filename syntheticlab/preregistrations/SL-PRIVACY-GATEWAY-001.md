# Preregistration — SL-PRIVACY-GATEWAY-001

## Required invariants

- common pre-fork history is accessible;
- post-fork sibling information is denied by default;
- explicit active scope-specific consent permits only the consented scope;
- revocation blocks future access;
- aggregate research does not require branch identifiers;
- ethics/safety review access does not imply sibling disclosure;
- all access attempts are auditable.
