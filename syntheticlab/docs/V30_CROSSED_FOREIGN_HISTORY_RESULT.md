## Supported conclusion

Supplying distinctive historical material as explicitly external reference context did not reproduce
the statistically detectable branch grouping observed when each branch received its own prior
history as autobiographical retrieval.

Neither the focal historical branch nor the external history source produced significant grouping
under the crossed control.

## Remaining confound

The v29 and v30 provider-facing source descriptions differed:

- v29 explicitly identified the retrieved material as prior lived-history evidence;
- v30 explicitly identified it as another branch's external history.

Therefore the current result demonstrates source-alignment specificity under the present provenance
framing, but does not yet distinguish:

- semantic matching between current SelfModel and historical content;
from
- explicit autobiographical ownership attribution.

v31 holds the actual own-history content constant while withholding the provider-facing relation
between that archive and the focal individual.
