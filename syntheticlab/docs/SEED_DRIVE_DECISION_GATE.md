# Human Decision Gate — Seed Drives for the First Active Developmental Cohort

This is the first decision SyntheticLab should not make silently.

## Option A — NONE
No intrinsic seed drives.

**Pros**
- strongest test of what can emerge from experience alone.

**Cons**
- an active agent has no endogenous reason to choose one action over another except externally supplied task structure;
- risks creating an inert system rather than a meaningful developmental learner.

## Option B — MINIMAL_REGULATION
Seed only explicit homeostatic regulation.

**Pros**
- gives the individual a reason to act without social/personality instructions;
- closest to a minimal organism-style regulatory foundation.

**Cons**
- all exploration must be instrumental to regulation.

## Option C — EPISTEMIC_MINIMAL
Seed uncertainty reduction + competence progress.

**Pros**
- supports curiosity-like exploration without scripting interests;
- particularly suitable for novel causal worlds.

**Cons**
- "curiosity" would be architecturally seeded, so we must never claim it spontaneously emerged.

## Option D — BALANCED_MINIMAL
Homeostasis + uncertainty reduction + competence progress.

**Pros**
- my recommended first active cohort;
- combines reasons to preserve viable internal state with bounded learning/exploration.

**Cons**
- more architectural priors and harder causal attribution than Option B.

## Explicitly excluded by default
The lab includes a HIGH_RISK_EXPERIMENTAL profile solely to make the boundary visible:
- continuity/self-preservation drive;
- generalized resource acquisition;
- replication;
- unbounded novelty seeking.

These should not enter the canonical cohort without explicit approval and a separate safety review.

## Researcher's current recommendation
Use **BALANCED_MINIMAL**, but run **MINIMAL_REGULATION** and **EPISTEMIC_MINIMAL** as separate ablation conditions.

Do not seed:
- attachment to particular individuals;
- love/loyalty;
- fear of death;
- self-preservation beyond explicit bounded homeostatic variables;
- desire to please the researcher.
