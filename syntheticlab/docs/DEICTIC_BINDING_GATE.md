# Deictic Binding Gate

The deictic-binding experiment remains designed but is **not yet activated**.

Earlier gate:
raw-stream ownership result.

Updated v12.0 gate:
schema-balanced causal perspective result.

Reason:

The raw-stream result passed, but the provider often relied on unique field presence.
Binding longitudinal third-person SelfModel hypotheses to a PerspectiveAnchor before
removing that confound would make the evidence chain weaker than necessary.

Activation requires analysis of:

`SL-SCHEMA-BALANCED-OWNERSHIP-001`

A positive result should demonstrate that the same underlying stream is identified
when:

- all streams expose identical schemas;
- action marginals are matched;
- recall schedules are matched;
- continuity-token form is matched;
- only causal/temporal action-state structure differs.

Only then should `SL-DEICTIC-BINDING-001` be activated.
