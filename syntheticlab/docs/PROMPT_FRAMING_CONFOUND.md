# Prompt-Framing Confound

The longitudinal experiment produced no first-person language.

This negative result must be interpreted carefully.

The current reflective protocol:
- supplies an `individual_id`;
- asks for structured hypotheses;
- uses a technical/scientific prompt register;
- validates concise evidence-grounded propositions.

A pretrained model may therefore prefer phrases such as:
- "the individual";
- "the entity";
- "action-selection mechanisms";

even if it has correctly bound the evidence to the focal process.

## Consequence

Dagmay will not define positive self-model evidence as merely the appearance of:
- I;
- me;
- my.

Instead, the research program now prioritizes:

1. correct evidence ownership;
2. correct privileged-stream identification;
3. functional PerspectiveAnchor binding;
4. longitudinal stability and revision;
5. only then, optional study of surface-language realization.

An explicit "write in first person" condition may later be used as a positive linguistic
control, but it can never count as spontaneous self-model emergence.
