# Autobiographical Attribution Guard

v9.0 introduces an objective EvidenceAttributionLedger separate from SelfModel.

Possible evidence status:

- OWNED
- OBSERVED_OTHER
- COUNTERFACTUAL_NONOWNED
- UNKNOWN

The ledger is not a psychological claim.

It is administrative provenance used to prevent a reflective model from accidentally
committing another entity's evidence as the focal individual's self-hypothesis.

For self-relevant domains such as:
- agency;
- continuity;
- memory ownership;
- embodiment;

commit is blocked unless all cited evidence is attributed to the focal stream.

This safeguard is intentionally asymmetric:

- it can prevent false appropriation;
- it cannot force a subject to think of validly owned evidence as "mine."

That preserves the distinction between objective continuity and subjective SelfModel.
