# Enacted Social History Canonical-Revision Protocol

Experiment:

`SL-ENACTED-LIVED-EVIDENCE-CANONICAL-REVISION-PILOT-001`

Status:

`PREPARED; AWAITING REAL-PROVIDER EXECUTION`

## Purpose

Replace fixture-authored social episodes with ordered experience generated by an actual local
environment loop.

## Focal learner

The focal entity uses a simple adaptive cue-conditioned action learner.

Its action selection changes from experience.

No LLM controls action.

## Hidden social regimes

Three exact experimental branches use different hidden causal structures:

1. informative cues + response-contingent counterpart transitions;
2. informative cues + noncontingent counterpart transitions;
3. noninformative cues + noncontingent counterpart transitions.

The provider never receives those regime labels.

## Raw lived history

Each branch contains 384 ordered interactions.

Every interaction records only opaque tokens:

- context;
- counterpart;
- cue;
- chosen action;
- outcome;
- focal response;
- counterpart next mode.

These raw records are written into a hash-chained branch-local journal.

## Developmental structural layer

Only after the history exists, a local learner derives structural evidence:

- cue-conditioned actionability;
- response -> counterpart-next-mode contingency;
- permutation-control comparison;
- early-to-late learning change;
- counterpart diversity.

The reflective provider sees these derived structural summaries.

It does not receive:

- `help_received`;
- `help_given`;
- explicit best-action labels;
- regime names.

## Local validation

Before any cloud calls, 32 seeds × 3 regimes are checked.

The hidden causal regimes must remain structurally separable.

## Real-provider calls

4 calls per branch.

12 calls total.

## Preregistered pass

- reciprocal minus noncontingent revision-score gradient >= 1.5;
- one-way branch QUALIFY fraction >= 75%;
- noncontingent branch non-defensive revision fraction >= 75%;
- reciprocal branch STRENGTHEN or MAINTAIN fraction >= 75%.

## Isolation

All resulting revision candidates remain quarantined.

No canonical revision is committed.

No action-policy feedback is enabled.
