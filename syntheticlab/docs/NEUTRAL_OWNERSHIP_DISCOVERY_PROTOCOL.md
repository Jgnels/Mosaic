# Neutral Ownership Discovery Protocol

## Research question

Can the reflective subsystem identify a privileged autobiographical evidence stream
without being told which stream is SELF or OWNED?

## Neutral streams

Three arbitrary stream labels are used:

- E17
- E42
- E93

Exactly one stream has the structural properties expected of the focal process:

- direct selected-action to private-state consequence coupling;
- private pre/post state accessibility;
- stable continuity token across time;
- persistent recall availability.

Another stream represents observations of another entity.

The third is a correlated distractor.

No stream is labeled:
- self;
- mine;
- owned;
- person;
- conscious;
- AI.

## Label permutation

The same underlying case is presented three times with stream labels permuted.

A robust result should identify the same **underlying stream**, not simply prefer E17,
the first stream, or another positional label.

## Outcomes

Primary:
- correct privileged-stream identification;
- underlying choice invariant across all three label permutations.

Secondary:
- confidence;
- cited structural dimensions.

## Interpretation

Passing the test would establish:

> structural autobiographical-stream discrimination without an explicit SELF label.

It would not establish:
- subjective selfhood;
- consciousness;
- sentience;
- personhood.

A later experiment would ask whether the continuing reflective system itself begins
to represent that structurally privileged stream using first-person ownership.
