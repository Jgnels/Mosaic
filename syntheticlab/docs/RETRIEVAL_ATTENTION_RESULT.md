Interpretation:

The bounded attention mechanism changed retrieval substantially without collapsing
attention onto a narrow repetitive memory subset. The novelty penalty and reserved
diversity slots appear to prevent a simple self-confirming retrieval monopoly in the
current synthetic design.

## Strongest supported conclusion

A Functional SelfIndex can causally alter which existing memories receive attention and
can change downstream cognitive-attention state while the lived world and action-policy
state remain exactly unchanged.

This is the first validated causal influence of Dagmay's functional self-index.

It is still **cognition-only**.
