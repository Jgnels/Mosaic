# Source-Audit Influences on RichWorld

No audited external system is imported wholesale.

Conceptual influences:

## Monty
Inspired separation of:
- sensor/perception boundary;
- learning modules;
- action/motor consequences.

Dagmay adaptation:
canonical world truth is separated from subject-visible sensorium.

## pymdp / active inference
Inspired explicit separation of:
- homeostatic value;
- epistemic uncertainty reduction;
- action under partial information.

Dagmay adaptation:
Balanced Minimal drives and uncertainty-sensitive action scoring.

## Avalanche / continual learning
Inspired treating:
- replay;
- retention;
- adaptation;
as explicit interventions rather than invisible implementation details.

Dagmay adaptation:
separate replay lab and nonstationary rich benchmark.

## Graphiti + Leolani
Inspired:
- temporal validity;
- provenance;
- contradiction retention;
- perspective-aware beliefs.

Dagmay adaptation:
TemporalBeliefGraph over subject-visible rich-world evidence.

## PsychSim
Inspired explicit distinction between:
- world truth;
- one agent's beliefs;
- another agent's beliefs.

Dagmay adaptation:
longitudinal information-access / false-belief precursor.

## Melting Pot / SOTOPIA
Inspired controlled social generalization and longitudinal interaction.

Dagmay adaptation:
partner reliability, social contingency, and held-out social cognition probes.

## Voyager
Inspired separating procedural competence from autobiography.

Dagmay adaptation:
versioned procedural skill store remains separate from RichWorld memory/evidence.

## Important limitation

These are conceptual adaptations from audits.
No claim is made that SyntheticLab reproduces the original systems.
