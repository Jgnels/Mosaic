# v1.2 Scientific Hardening

The v1.0 results were reviewed for ceiling effects rather than treated as accomplishments.

Changes:
- segmentation now includes nuisance changes and false surprise spikes;
- replay now uses shared parameters and ongoing interference;
- ToM precursor learns an information-access rule from repeated episodes;
- relationship state now drives a future partner choice probe;
- cross-environment transfer isolates strategy transfer from semantic knowledge;
- curriculum experiments select challenges, not personalities;
- persistence restart is tested at an exact state-hash level.

The next blocked feature is a real reflective LLM, because disclosure/self-knowledge changes the scientific object being studied.
