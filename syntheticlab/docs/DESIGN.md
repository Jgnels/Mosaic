## v0.1 principles

### Opaque symbols
Psychologically loaded labels are excluded from the causal-learning experiment.

### Hidden oracle state
The environment knows the true causal rules. The learner does not.

### Individual history
A learner's state changes only through the experiences supplied to that learner.

### Exact forks
Branch experiments hash the full learner state before divergence.

### Provenance
Context-action estimates record the event IDs contributing to them.

### Positive control
An oracle agent is supplied the answer. This prevents us from confusing identical outward success with identical developmental processes.

### No LLM
v0.1 deliberately contains no language model. This isolates causal learning from pretrained language priors.

## Explicit non-claims

SyntheticLab v0.1 does not demonstrate:
- selfhood;
- personhood;
- consciousness;
- human-like childhood;
- human emotion;
- intrinsic motivation.

It creates infrastructure for controlled tests of narrower prerequisites.
