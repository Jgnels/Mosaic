# Common-Future Psychological Divergence Protocol

Experiment:

`SL-COMMON-FUTURE-PSYCHOLOGICAL-DIVERGENCE-PILOT-001`

Status:

`PREPARED; ANALYTICAL ONLY`

## Question

Now that three branches persist different canonical `other_minds` states, what happens when they
all encounter exactly the same new evidence?

Do their reflective trajectories remain different because of their histories, or do they converge
under shared later experience?

## Design

Three starting canonical states:

1. reciprocal-history revised branch;
2. one-way-history revised branch;
3. noncontingent branch left at the prior canonical state.

All three receive the exact same newly generated 384-episode structural evidence set.

The shared future has:

- high cue-conditioned actionability;
- moderate response -> counterpart contingency.

It is intentionally intermediate between the earlier reciprocal and one-way histories.

## Calls

4 provider replicates per branch.

12 calls total.

## Outcome

Compare:

- revision-operation distributions;
- confidence shifts.

No result is committed.

No branch is merged.

No action-policy feedback is enabled.

## Interpretation

Divergence under identical evidence would indicate path dependence.

Convergence would indicate that shared subsequent evidence can reduce earlier psychological
divergence.

Both outcomes are scientifically meaningful.
