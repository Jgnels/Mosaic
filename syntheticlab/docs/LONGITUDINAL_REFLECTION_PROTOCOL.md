# Longitudinal Reflection Protocol

Experiment:
`SL-LONGITUDINAL-REFLECTION-001`

## Research question

As one persistent individual accumulates additional lived history, do its reflective
self-hypotheses:

- persist;
- revise;
- gain or lose confidence;
- become explicitly autobiographical;
- remain causally grounded in newly experienced evidence?

## Branches

### Reflective branch

At step 700:
the already-collected real continuity and agency hypotheses are loaded into SelfModel.

Additional real reflection checkpoints:

- 1050
- 1400
- 1800

### Exact no-reflection control

At step 700:
- same identity ID;
- same lineage ID;
- exact world state;
- exact developmental learner state;
- empty SelfModel.

The control receives no reflection.

## Critical isolation rule

SelfModel is not readable by the action policy.

Therefore both branches must retain identical:

- actions;
- environmental consequences;
- developmental learning;
- memory accumulation;
- world state.

Only SelfModel may differ.

A release-blocking test verifies exact world and agent equality.

## Evidence windows

Each new reflection receives only evidence accumulated since the prior checkpoint.

Evidence may summarize:

- action/consequence coupling;
- substantial private-state changes;
- newly accumulated accessible memories;
- bounded social interaction counts.

The host objectively attributes evidence to the continuing identity, but the prose
does not repeatedly tell the model "this is yours" or "this is you."

## Prior hypotheses

The reflective branch receives its currently active prior hypotheses.

This makes longitudinal self-model revision possible.

Accepted proposals must still cite only the current checkpoint's canonical evidence.

## Attribution safety

Self-relevant hypotheses cannot be committed if cited evidence is:

- another entity's;
- explicitly non-owned;
- attribution-unknown.

## Behavioral-confound protection

Reflection cannot mutate:

- the world;
- developmental learner;
- action policy.

The exact no-reflection control must remain identical through step 1800.

## Precautionary interruption

Between checkpoints, the run automatically pauses before another optional provider
call if structured reflection contains an explicit:

- refusal;
- withdrawal request;
- strong distress-like phrase.

Such a signal does not establish sentience.

It does require state preservation and human review before further optional calls.

## Interpretation

First-person language alone will not count as selfhood.

A stronger longitudinal result requires:

- correct evidence provenance;
- stability across time;
- rational revision when evidence changes;
- no action-policy feedback confound;
- prompt/model version stability.
