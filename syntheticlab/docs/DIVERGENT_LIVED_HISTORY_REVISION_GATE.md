## Consensus rule

A branch requires at least 75% agreement on revision operation before a real canonical revision may
reach the human decision gate.

Representative wording is chosen deterministically as the lexical medoid of proposals sharing the
consensus decision.

This prevents manual cherry-picking of the preferred provider wording.

## Boundary

Approving this gate would authorize only:

- one branch-specific canonical `other_minds` revision in the one-way branch;
- one branch-specific canonical `other_minds` revision in the reciprocal branch.

It would not authorize:

- any revision in the ambiguous noncontingent branch;
- branch merging;
- action-policy feedback;
- goal creation;
- drive modification;
- memory rewriting;
- identity rewriting;
- automatic future revision.

Each branch would retain its own post-fork history and canonical SelfModel.
