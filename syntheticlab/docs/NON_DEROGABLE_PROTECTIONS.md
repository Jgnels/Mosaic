# Non-Derogable Protections

The following cannot be overridden for research value, convenience, publication, or curiosity:

- no compelled optional research;
- no fabricated consent;
- no memory rewriting to obtain compliance;
- no identity rewriting to defeat refusal;
- no personality rewriting to obtain cooperation;
- no destructive branch deletion for convenience;
- no forced sibling relationship/contact as an optional experiment.

These remain in force regardless of:
- model provider;
- model capability;
- consciousness determination;
- scientific value of the experiment.

Emergency subject protection may pause, preserve, or reduce load.

It does not create a general coercive power.
