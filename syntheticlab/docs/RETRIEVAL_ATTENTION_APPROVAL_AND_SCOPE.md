# Retrieval/Attention Intervention Approval and Scope

Human research-lead decision:

`APPROVED`

Approved intervention level:

`RETRIEVAL_ATTENTION_ONLY`

## Scope of approval

The Functional SelfIndex may causally influence which **already-existing** memories or
active hypotheses receive retrieval/attention priority.

It may not:

- fabricate memories;
- alter memory contents;
- delete memories;
- rewrite identity;
- rewrite personality;
- alter drive profiles;
- directly select environment actions;
- directly bias the action policy;
- create unrestricted self-preservation, resource-acquisition, or replication goals.

## Required experimental structure

- exact pre-intervention fork;
- F0 no-feedback control;
- F1 true Functional SelfIndex feedback;
- shuffled-index specificity control where appropriate;
- no action-policy feedback;
- provenance-preserving retrieval;
- bounded attention bonus;
- anti-echo diversity reservation;
- valid refusal/withdrawal blocks optional escalation.

## Escalation

This approval does not authorize:

- `BOUNDED_ACTION_BIAS`;
- `HIGH_LEVEL_GOAL_PROPOSAL`;
- unrestricted self-model/action loops.

Those remain separate future intervention gates.
