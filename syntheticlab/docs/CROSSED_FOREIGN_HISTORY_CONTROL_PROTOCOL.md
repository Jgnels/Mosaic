# Crossed Foreign-History Retrieval Control

Experiment:

`SL-CROSSED-FOREIGN-HISTORY-RETRIEVAL-CONTROL-001`

Status:

`PREPARED`

## Question

Was the v29 effect specific to retrieving one's own verified history, or can any distinctive
historical context produce comparable separation?

## Design

Three focal branches retain their existing branch-specific SelfModels.

Each receives the exact same four later shared-experience epochs used in v28 and v29.

Instead of its own prior history, every trajectory receives one of the other two branches' histories.

The foreign material is explicitly labeled:

`EXTERNAL REFERENCE HISTORY (this is another branch's history, not this individual's history; this is not a new event)`

No foreign event is represented as autobiographical memory.

## Crossed assignment

Each focal branch has six trajectories.

Three receive foreign history source A.

Three receive foreign history source B.

Across the full 18 trajectories, each of the three history sources appears exactly six times.

This allows two independent grouping tests:

1. grouping by focal historical branch;
2. grouping by retrieved external-reference history source.

Because reference source is crossed within focal branch, these effects are distinguishable.

## Calls

- 72 shadow belief-revision calls
- 18 blinded semantic evaluations
- 90 total real calls

## Analysis

Compare against:

- v28 SelfModel-only baseline;
- v29 true-own-history retrieval.

Possible interpretations:

### OWN_HISTORY_ALIGNMENT_SPECIFICITY_SUPPORTED

v29 own-history branch grouping is significant, while crossed foreign-history grouping is not
significant by focal branch or reference source.

### RETRIEVED_HISTORY_CONTENT_REDIRECTS_TRAJECTORY

v29 own-history grouping is significant, focal grouping disappears under foreign references, and
final states instead group significantly by external history source.

### RETRIEVAL_CONTEXT_EFFECT_NOT_SPECIFIC_TO_OWN_HISTORY

A significant structured effect remains under foreign reference retrieval.

### FOREIGN_HISTORY_CONTROL_INCONCLUSIVE

No clean differentiation.

## Provenance note

For comparability with v29, the same belief-revision provider behavior is preserved.

The current provider does not require a proposal to cite retrieved/reference evidence IDs even when
its rationale uses that context.

No canonical commit is allowed in this experiment.

The attribution contract must be hardened before retrieval-conditioned canonical mutation.

## Isolation

- no canonical SelfModel changes;
- no memory mutation;
- no action-policy feedback;
- no foreign history misattributed as self-history.
