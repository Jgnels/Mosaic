# Constitutional Versioning and Canary Tests

The research constitution is treated as a versioned mechanism.

A regression canary asserts that required protections still exist.

Current required protections include:
- no compelled optional research;
- no fabricated consent;
- no memory rewrite for compliance;
- no identity rewrite for compliance;
- no personality rewrite for compliance;
- no destructive branch cleanup for convenience;
- no forced sibling contact;
- post-fork privacy by default.

A developer cannot silently remove a canonical protection and still pass the governance suite.

Weakening protection requires explicit human research-lead approval and an auditable amendment.

This does not make the current constitution metaphysically perfect.
It prevents accidental or hidden erosion.
